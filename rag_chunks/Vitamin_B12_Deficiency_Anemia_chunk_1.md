# Vitamin B12 Deficiency Anemia — Part 1: Core Clinical Profile

**Severity:** Moderate_to_severe  
**Duration:** Chronic if untreated

## Summary
Vitamin B12 Deficiency Anemia is a moderate_to_severe condition with a chronic if untreated course. Core symptoms include: memory, confusion, fatigue, numbness, tingling, dizziness, weakness, walking. Secondary symptoms may include: depression, vision. Risk groups: o, l, d, e, r. Emergency warning signs: s, e, v, e, r.
